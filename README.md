# 🚀 AI/OS - Modern SaaS & AI Landing Page

A modern, responsive, and high-converting landing page designed for AI-powered software and SaaS platforms. Built with clean semantic HTML5, modern CSS3 (Flexbox, CSS Variables, Media Queries), and Vanilla JavaScript.

![AI/OS Landing Page Preview](assets/illustration.jpg)

## ✨ Features

- **Modern Dark Theme & Cyberpunk/Neon Aesthetics:** Designed with deep contrast colors, neon accents, and soft glow effects to prevent eye strain.
- **Fully Responsive Layout:** Optimized for mobile phones, tablets, and desktop screens.
- **Interactive Mobile Menu (Hamburger Menu):** Smooth slide-in navigation panel with dynamic icon toggling via JavaScript.
- **Interactive UI Cards:** Clean CSS card components featuring smooth hover animations and depth effects.
- **Accessibility & SEO Best Practices:** Built using semantic HTML tags (`header`, `main`, `section`, `article`, `nav`) and structured accessibility attributes.

---

## 🛠️ Built With

- **HTML5** (Semantic Markup)
- **CSS3** (Flexbox, CSS Variables, Custom Gradients, Media Queries)
- **JavaScript (ES6+)** (DOM Manipulation & Mobile Menu Toggle)
- **Google Fonts** (Inter)
- **FontAwesome** (Modern Icons)
